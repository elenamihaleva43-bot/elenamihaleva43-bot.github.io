§1.Линейное уравнение ax + b = 0 с параметром

10 класс · профильный уровень

Что значит «решить уравнение с параметром»

Решить уравнение с параметром — значит выяснить, при каких значениях параметра решения вообще существуют, сколько их, и в случае их существования дать формулы решения, то есть выразить x через параметры.

Это напоминает составление программы (алгоритма) для вычислительной машины: если мы берём одно конкретное значение параметра — пользуемся одной формулой; если другое — решение получится по другим формулам; а при некотором значении параметра решений нет вовсе.

Пользователь, «вводя» любое значение параметра, должен получить полную информацию о решении уравнения в этих условиях. Отсюда — особая форма записи ответа, по которой сразу видно, какое будет решение для каждого значения параметра.

Образцы решения на полный балл

Разберите решение каждого примера пошагово. Пишите параллельно на клетчатом поле справа.

Пример 1 · (1 + a)x = 3a при a = 1
Шаг 1 из 4
Условие: (1 + a)x = 3a, a = 1.
При a ≠ −1, в том числе и при a = 1, коэффициент при x отличен от нуля.
Делим обе части на (1 + a) ≠ 0 — находим единственный корень. В общем виде: x = 3a / (a + 1).
Подставляем a = 1: x = 3·1 / (1+1) = 1,5.
Ответ: при a = 1 — единственный корень x = 1,5
Пример 2 · 2a · x = 2 − a при a = 0
Шаг 1 из 3
Условие: 2a · x = 2 − a, a = 0.
Если a = 0, левая часть обращается в нуль при любом значении x.
Правая часть при этом: 2 − a = 2 ≠ 0. Уравнение принимает вид 0 · x = 2 — решений нет.
Ответ: при a = 0 — корней нет
Пример 3 · (4 − a²)x = (a − 2)² при a = 2
Шаг 1 из 3
Условие: (4 − a²)x = (a − 2)², a = 2.
Если a = 2, левая часть: (4 − 4)x = 0 — обращается в нуль при любом x.
Правая часть: (2 − 2)² = 0 — тоже равна нулю. Уравнение принимает вид 0 · x = 0 — ему удовлетворяет любое x.
Ответ: при a = 2 — x ∈ ℝ (бесконечно много корней)

Вывод. Если нужно найти решение при конкретном значении параметра — просто подставляем это число и решаем полученное числовое уравнение.

Образцы решения на полный балл · Часть 2

Исследование: при каком значении параметра уравнение имеет…

Вопрос 1 · (a − 2)² · x = 1 − a² — ровно один корень
Шаг 1 из 3
Уравнение имеет ровно один корень, если коэффициент при x отличен от нуля.
Коэффициент: (a − 2)² = 0 при a = 2.
Значит, при a ≠ 2 коэффициент не равен нулю — ровно один корень.
Ответ: a ≠ 2
Вопрос 2 · 3a · x = 2 − 2a — не имеет корней
Шаг 1 из 3
Уравнение не имеет корней, если коэффициент при x равен нулю, а свободный член отличен от нуля.
Коэффициент: 3a = 0 при a = 0.
Проверяем свободный член при a = 0: 2 − 2a = 2 ≠ 0. Условие выполняется.
Ответ: a = 0
Вопрос 3 · (a² − 1) · x = 2 + 2a — бесконечно много корней
Шаг 1 из 4
Уравнение имеет бесконечно много корней, если коэффициент при x равен нулю и свободный член тоже равен нулю.
Коэффициент: a² − 1 = 0 → a = 1 или a = −1.
Проверяем свободный член: при a = 1: 2 + 2 = 4 ≠ 0 — не подходит. При a = −1: 2 − 2 = 0 — подходит.
Ответ: a = −1
