§1.Линейное уравнение ax + b = 0 с параметром

10 класс · профильный уровень · ΤΕΤΡΑΚΤΥΣ

Что значит «решить уравнение с параметром»

Решить уравнение с параметром — значит выяснить, при каких значениях параметра решения вообще существуют, сколько их, и в случае их существования дать формулы решения, то есть выразить x через параметры.

Это напоминает составление программы (алгоритма) для вычислительной машины: если мы берём одно конкретное значение параметра — пользуемся одной формулой; если другое — решение получится по другим формулам; а при некотором значении параметра решений нет вовсе.

Пользователь, «вводя» любое значение параметра, должен получить полную информацию о решении уравнения в этих условиях. Отсюда — особая форма записи ответа, по которой сразу видно, какое будет решение для каждого значения параметра.

Практическое задание. Заполните таблицу

Придумайте несколько примеров под каждый тип линейного уравнения с параметром. Запишите уравнения в соответствующую колонку.

Имеет бесконечно много корней

Три случая для уравнения ax = b

Единственный корень
a ≠ 0
x = ba
Нет корней
a = 0, b ≠ 0
0 · x = b ≠ 0
Бесконечно много
a = 0, b = 0
0 · x = 0 → x ∈ ℝ

Именно эти три случая лежат в основе всех дальнейших рассуждений. Всё, что мы делаем с параметром, — это разбираем, в какой из трёх случаев попадает уравнение при каждом значении параметра.
