Прямая y = kx + b с параметром · 5 заданий
1 Прямая через две точки
1)Уравнение прямой: y = kx + b. Подставляем координаты точек A(1; 4) и B(4; −5):
2)4 = k + b и −5 = 4k + b.
3)Вычитаем первое из второго: −9 = 3k, значит k = −3.
4)Тогда b = 4 − k = 4 + 3 = 7. Уравнение: y = −3x + 7.
5)Пересечение с Ox: y = 0: −3x + 7 = 0 → x = 7/3.
Ответ: x = 7/3 (≈ 2,33)
2 Неподвижная точка
1)Группируем правую часть по a:
2)y = (a − 3)x + 2a − 6 = a(x + 2) − 3x − 6.
3)Чтобы y не зависело от a, нужно x + 2 = 0, то есть x = −2.
4)Тогда y = −3·(−2) − 6 = 6 − 6 = 0.
Ответ: (−2; 0)
3 Параллельность
1)Прямые параллельны, если их угловые коэффициенты равны: k = 3.
2)Подставляем точку (1; 5) в уравнение y = 3x + b:
3)5 = 3·1 + b → b = 2.
Ответ: b = 2
4 Перпендикулярность
1)Прямые перпендикулярны, если k₁ · k₂ = −1.
2)Дано: k₁ = 2, значит k₂ = −1/2.
3)Подставляем точку (4; 1): 1 = −1/2 · 4 + b → 1 = −2 + b → b = 3.
4)Уравнение: y = −1/2·x + 3. Пересечение с Oy — при x = 0: y = 3.
Ответ: (0; 3)
5 Параметр
1)Уравнение прямой: y = a²x − 3ax + 4a − 12 = (a² − 3a)x + (4a − 12).
2)Чтобы не иметь общих точек с y = x + 5, прямые должны быть параллельны:
3)Коэффициент при x совпадает с 1: a² − 3a = 1 → a² − 3a − 1 = 0.
4)Корни: a = (3 ± √13) / 2. Наименьший из них — (3 − √13) / 2.
Ответ: a = (3 − √13) / 2
