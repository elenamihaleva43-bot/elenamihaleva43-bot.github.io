Ответы · ДЗ-5 «Много точек»

Для проверки · 4 задания · метод интервалов
Задание 1
(x−1)(x−2)²(x−3)³(x−4)⁴ ≤ 0
Эталонный ответ
( −∞ ; 3 ] ∪ { 4 }
Решение:
1. Нули: x = 1 (нечёт.), x = 2 (чёт.), x = 3 (нечёт.), x = 4 (чёт.). 2. Знаки по интервалам:    (−∞; 1) → +    (1; 2) → −    (2; 3) → − (петля на 2: не меняется)    (3; 4) → + (меняется через 3)    (4; +∞) → + (петля на 4: не меняется) 3. ≤ 0 → берём минусы: (1; 3) и нули: x = 1, 3, 4. 4. Точка 2 — тоже нуль (чётная кратность) → включается.
Ответ: ( −∞ ; 3 ] ∪ { 4 }
Задание 2
x(x−1)²(x−2)³(x−3)⁴(x+1)⁵(x+2)⁶(x+3)⁷ ≥ 0
Эталонный ответ
( −∞ ; −3 ) ∪ ( −3 ; −2 ) ∪ ( −2 ; −1 ) ∪ [ 0 ; +∞ )
Решение:
1. Числитель: x = 0, x = 1 (чёт.), x = 2, x = 3 (чёт.). 2. Знаменатель: x = −1, x = −2 (чёт.), x = −3 — все выколоты. 3. Знаки: (−∞;−3)+, (−3;−2)+, (−2;−1)−, (−1;0)+, (0;1)+, (1;2)+, (2;3)−, (3;+∞)+. 4. ≥ 0 → все плюсы + нули. 5. x = 3 — нуль чётной кратности, f(3) = 0 ≥ 0 → включается.
Ответ: ( −∞ ; −3 ) ∪ ( −3 ; −2 ) ∪ ( −2 ; −1 ) ∪ [ 0 ; +∞ )
Задание 3
(x−9)⁹(x+8)⁸(x−7)⁷(x+6)⁶ ≤ 0
Эталонный ответ
{ 7 } ∪ [ 9 ; +∞ )
Решение:
1. Нули: x = 9 (нечёт.), x = −8 (чёт.), x = 7 (нечёт.), x = −6 (чёт.). 2. Знаки: (−∞;−8)+, [−8;−6)+, [−6;7)+, [7;9)−, [9;+∞)+. 3. ≤ 0 → минус: (7; 9). 4. Нули: x = 7, x = 9 — включаются.
Ответ: { 7 } ∪ [ 9 ; +∞ )
Задание 4
(x+1)(x+2)²(x+3)³(x+4)⁴(x+5)⁵(x+6)⁶ ≥ 0
Эталонный ответ
( −∞ ; −6 ) ∪ ( −6 ; −5 ) ∪ [ −3 ; +∞ )
Решение:
1. Нули числ.: x = −1, x = −2 (чёт.), x = −3. 2. Нули знам.: x = −4 (чёт.), x = −5, x = −6 (чёт.) — выколоты. 3. Знаки: (−∞;−6)+, (−6;−5)+, (−5;−4)−, (−4;−3)+, (−3;−2)+, (−2;−1)+, [−1;+∞)+. 4. ≥ 0 → все плюсы + нули: x = −3, −2, −1.
Ответ: ( −∞ ; −6 ) ∪ ( −6 ; −5 ) ∪ [ −3 ; +∞ )
