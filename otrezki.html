📖 Определения
Что такое отрезок и его длина

📌 Что такое отрезок?

Отрезок — это часть прямой, ограниченная двумя точками.
Точки называются концами отрезка.

📌 Длина отрезка

Длина отрезка — это расстояние между его концами.
Обозначается: AB.

📌 Свойство длины

Если точка C лежит на отрезке AB, то
AB = AC + CB.

🎯 Попробуй! Измерь длину отрезка
Двигай точку B — линейка покажет длину отрезка AB.
Точка A (начало) Точка B (конец)
📍 A = 0 📍 B = 5.0 📏 AB = 5.0
💡 Потяни за синюю точку (B), чтобы изменить длину отрезка.

📌 Тренажёр 2. Найди весь отрезок

Найди AB.

📌 Тренажёр 3. Найди часть отрезка
Точка C лежит на отрезке AB.
AC — известен, AB — известен.
Найди CB.
Точка A Точка C (двигай) Точка B (двигай)
AC = 3 AB = 8 CB = ?
