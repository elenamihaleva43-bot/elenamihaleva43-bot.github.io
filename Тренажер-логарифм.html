📖 Свойства логарифмов

Определение

loga b = c  ⇔  ac = b a > 0, a ≠ 1, b > 0

Основное тождество

aloga b = b логарифм и степень «съедают» друг друга

Простейшие значения

loga 1 = 0
loga a = 1

Логарифм произведения

loga (xy) = loga x + loga y

Логарифм частного

loga xy = loga x − loga y

Логарифм степени

loga (xn) = n · loga x степень можно выносить вперёд

Переход к новому основанию

loga b = logc blogc a

Следствие

loga b = 1logb a

Десятичный и натуральный

lg x = log10 x
ln x = loge x e ≈ 2,718…

Важно помнить

• a > 0, a ≠ 1
• b > 0 (аргумент)
• x > 0, y > 0 в свойствах суммы и разности
