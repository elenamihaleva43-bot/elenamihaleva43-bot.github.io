{
x² − 9 ≤ 0
x + 1 > 0
1) Решаем первое неравенство: x² − 9 ≤ 0 → (x−3)(x+3) ≤ 0 → x ∈ [−3; 3].
2) Решаем второе: x + 1 > 0 → x > −1 → x ∈ (−1; +∞).
3) Ищем пересечение: [−3; 3] ∩ (−1; +∞) = (−1; 3].
Ответ: (−1; 3]

3) Пересечение: ((−∞; 0) ∪ (5; +∞)) ∩ (−∞; 7) = (−∞; 0) ∪ (5; 7).
Ответ: (−∞; 0) ∪ (5; 7)
